# Scientific figure workflow

Use `ai4scholar_figure` only for explicit figure work. Calls may consume credits, and generated scientific content must be treated as a draft.

## Workflow

1. Establish the scientific message, audience, required labels, aspect ratio, language, style, and output purpose.
2. Use `smart` or `generate` for new figures; `edit`, `style`, `compose`, or `iterate` for supplied public image URLs; `critic` for review; `vectorize` for conversion.
3. Select model and image size proportionate to the task. Avoid expensive high-resolution calls during early exploration.
4. Preserve factual labels, units, molecular structures, mechanisms, and relative directions supplied by the user.
5. After generation, verify spelling, label placement, causal arrows, structures, legends, scales, and quantitative statements.
6. Explicitly identify any element that requires expert validation before publication. Never present a generated diagram as experimental evidence.
